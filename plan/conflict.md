# 충돌 해결 사례

## 회원탈퇴 후 로그인 화면 이동 기능 — Revert 충돌

같은 기능(회원탈퇴 후 로그인 화면 이동)을 두 사람이 조율 없이 동시에 수정하면서 발생한 되돌림(revert) 사고.

| 시간 | 누가 | 커밋 | 내용 |
|---|---|---|---|
| 2026-09-16 11:39 | paaaraaaeaaa (김예린) | `067f9fc` | fix(my-page): 일반 회원탈퇴 후 로그인 화면으로 이동하지 않던 문제 수정 |
| 2026-09-16 11:52 | yang7493 (양다연) | `1e8c103` | Revert "fix(my-page): 일반 회원탈퇴 후 로그인 화면으로 이동하지 않던 문제 수정" |
| 2026-09-16 12:02 | paaaraaaeaaa (김예린) | `7f59765` | fix(my-page): 회원탈퇴 후 로그인 화면 이동 재적용 |

### 어디서, 왜 생겼나
- 파일: 회원탈퇴/로그인 이동 관련 my-page 코드 (인증·마이페이지 영역)
- 13분 만에 한 사람의 수정이 다른 사람에 의해 되돌려지고, 10분 뒤 원래 작성자가 다시 적용함
- 커밋 메시지가 정확히 같은 기능을 가리키고 있어, 같은 영역을 두 사람이 사전 공유 없이 동시에 수정하다가 충돌한 것으로 보임 [확인 필요: 실제 충돌 원인(코드 충돌 vs 의도적 되돌림)은 코드/PR 이력으로 추가 확인 필요]

### 어떻게 해결했나
- 되돌려진 수정을 원 작성자가 다시 적용(`7f59765`)해서 최종적으로는 수정 사항이 반영됨

### 개선안
- 같은 영역(인증/마이페이지 등) 작업 전에 이슈나 Slack으로 담당·범위를 먼저 공지
- PR 단위로 병합해 리뷰를 거치면 이런 되돌림이 리뷰 단계에서 먼저 걸러졌을 것
